# minoplay.github.io

Serves `/.well-known/assetlinks.json`, which lets the ProgressiveOverload Android app
(`io.github.minoplay.progressiveoverload`) open https://minoplay.github.io/ProgressiveOverload/ fullscreen.
Do not delete this repository. See `.github/features/android-app.md` in MinoPlay/ProgressiveOverload.
